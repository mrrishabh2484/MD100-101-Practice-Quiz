1MD-100 · Deploy

Which two hardware features are mandatory for a Windows 11 installation?

  • A. BIOS and MBR disk
  • B. TPM 2.0 and UEFI Secure Boot
  • C. 32-bit CPU and 2 GB RAM
  • D. Legacy boot and a GPT disk
Reveal answer & explanation

Correct answer: B. TPM 2.0 and UEFI Secure Boot

Windows 11 requires TPM 2.0 and UEFI firmware with Secure Boot capability, along with a 64-bit CPU, 4 GB RAM, and 64 GB storage.

2MD-100 · Deploy

  • A. USMT (ScanState and LoadState)
  • B. BitLocker
  • C. Windows Configuration Designer
  • D. Storage Spaces

Correct answer: A. USMT (ScanState and LoadState)

The User State Migration Tool captures state with ScanState and restores it with LoadState. It supports side-by-side and wipe-and-load migrations.

7MD-100 · Devices & Data

A folder has NTFS 'Modify' for a user but the Share permission is 'Read'. What is the effective permission when the user connects over the network?

  • A. Modify
  • B. Full Control
  • C. Read
  • D. No access
Reveal answer & explanation

Correct answer: C. Read

When NTFS and Share permissions combine over the network, the most restrictive effective permission applies. Read is more restrictive than Modify.

8MD-100 · Devices & Data

A user has Allow-Read via a group and an explicit Deny-Write on a file. What can they do?

  • A. Read and write
  • B. Read only; write is denied
  • C. Nothing
  • D. Full control
Reveal answer & explanation

Correct answer: B. Read only; write is denied

Permissions are cumulative, but an explicit Deny overrides Allow. The user keeps Read but is denied Write.

9MD-100 · Devices & Data

You move a file to a different folder on the SAME NTFS volume. What happens to its permissions?

  • A. It inherits the destination's permissions
  • B. It keeps its original permissions
  • C. All permissions are removed
  • D. It becomes read-only
Reveal answer & explanation

Correct answer: B. It keeps its original permissions

Moving within the same NTFS volume retains original permissions. Copying, or moving to a different volume, inherits the destination's permissions.
